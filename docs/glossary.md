# Глоссарий (термины пользователя)

Живой словарь разговорных/рабочих терминов пользователя. Пополняется по мере
появления новых терминов (новые — в конец). Если в запросе встретился термин
отсюда — трактовать так, как написано ниже.

## Связка
Кабинет продавца: трёхуровневая иерархия «пользователь → фирма → маркетплейс».
Одна связка = одна фирма × один маркетплейс (WB или Ozon), поэтому у одной фирмы
связок может быть несколько. В шапке активная связка показана трёхсоставной
подписью «Пользователь * Фирма» плюс бейдж маркетплейса (напр.
`Константин Прудников * ИП Прудников Константин Григорьевич` + `WB`); нажатие
открывает селектор со списком всех связок. В коде — сущность `Cabinet`
(`app/models.py`), каждой связке соответствует отдельная схема БД `cab_<…>`;
активная связка хранится в куке `agent_cabinet`, «главная» — `main_cabinet_id`.

## Закоммитить
Зафиксировать изменения в git локально (`git commit`), никуда не отправляя.

## Закомпушить (закомпушь, компушить)
Выполнить полный git-цикл, чтобы сохранить текущее состояние приложения и
отразить его на GitHub: закоммитить, синхронизировать локальную ветку с
`origin/main` (pull/rebase) и запушить (`git push`). Всё, что нужно для
«сохранено и лежит на гитхабе».

## Юай (ю-ай; от англ. UI, user interface)
Пользовательский интерфейс: всё, что видит и с чем работает человек в браузере.
В проекте — фронтенд `app/static/` (`index.html`, `app.js`, `style.css`,
`columns.json`).

## Селектор
Элемент интерфейса: кнопка, по нажатию раскрывающая вложенное меню (список) для
выбора одного варианта. Примеры: селектор связки в шапке, меню «WB API / Ozon
API», фильтр маркетплейса. Синонимы: выпадающий список, дропдаун.

## Забэкапь (забэкапить)
Сделать резервную копию (бэкап). Без уточнений — копия базы данных. Если объект
назван явно, копируется именно он: напр. «забэкапь приложение полностью» — копия
всего приложения со всеми связанными структурами (БД, файлы/данные, настройки).

## ВБ (вайлдберриз, WB)
Маркетплейс Wildberries. В запросах пользователя — «ВБ», «вайлдберриз», в коде и
документации проекта — сокращение `WB` (`app/providers/wb.py`, токен `WB_API_KEY`,
бейдж `WB` в шапке связки). Второй маркетплейс проекта — Ozon (в коде `oz`);
если в задаче не назван Ozon явно, «ВБ» означает именно Wildberries. Не путать
с сервисами внутри маркетплейса («WB Клуб», «WB Продвижение», «WB Медиа»).

## Не тупи, братан
Реплика-команда: остановись, откатись к последнему моменту, где работа шла
толково (тупить начал раньше текущего шага), определи вслух этот момент и
продолжи выполнение задачи именно оттуда, без повторных блужданий. Признак
«тупления» — пустая/ошибочная возня (лишние чтения, откаты, повторные правки
одного места) вместо движения к цели.

## ABC/XYZ-анализ
Раздел «Обзор»: два разреза ассортимента. **ABC** — вклад товара в выручку
(A — первые 80 %, B — до 95 %, C — остальное), **XYZ** — стабильность спроса
(классы X/Y/Z/«Новинка»). Считается только по WB: помесячной детализации Ozon
нет. На пересечении — матрица 3×4 (A/B/C × X/Y/Z/Новинка) с выручкой,
прибылью и долей в ячейке; клик по ячейке раскрывает список артикулов этой
ячейки (артикул, наименование, ср. шт/мес., CV, активные месяцы, выручка,
прибыль) с копированием артикулов в буфер.

## Класс «Новинка» (NEW)
Товар, у которого в окне анализа (12 мес.) меньше активных месяцев, чем
заданный порог, — спрос оценить пока не по чему, в X/Y/Z он не попадает.
Порог выбирается в разделе (6 / 3 / 1 активных месяцев), по умолчанию 6;
в API — параметр `min_active_months` у `GET /api/dashboard/xyz`.

## CV (коэффициент вариации)
Мера колебаний помесячного спроса: σ/μ в процентах. Чем меньше CV, тем
стабильнее продажи. Границы классов X/Y/Z — терцили CV по товарам с
достаточной историей (не фиксированные 0.5/1.0: на этом ассортименте почти
всё попало бы в Z).
