Автопилот меняет только скидку (базовую цену карточки не трогает), опирается на данные воронки и фактическую маржу из детализации и не опускает витринную цену ниже порога убытка и минимальной цены WB. «Применить» в шапке пересчитывает рекомендации, «Применить в WB» вносит новые скидки через API (доступно, когда для всех снижений известна минимальная цена WB).
?Решение зависит от конверсии, динамики продаж и порога безубыточности: цена поднимается только при реальных продажах и хороших сигналах, докупаемые товары поднимаются умеренно. Кнопка «Применить в WB» вносит новые скидки через API; она активна, когда публичный Price API вернул минимальные цены для всех рекомендаций на снижение.

Журнал решений

Экспорт в Excel

Начальные (стартовые) остатки — отправная точка складского учёта. Дальше остатки считаются: начальные + Приход − Отгрузка.

Выгрузить в Excel

Поставщики, покупатели и маркетплейсы (Wildberries и Ozon — тоже контрагенты). Колонки файла: Наименование | ИНН | Тип | Телефон | Примечание.

Выгрузить в Excel Шаблон

Приход товара. Файл = пачка накладных: Дата | № документа | Контрагент | Артикул | Кол-во | Цена. Строки с одинаковыми №+дата+контрагент — один документ; повторная загрузка обновит документы.

Выгрузить в Excel Шаблон

Отгрузка товара (покупателю или на склад маркетплейса — контрагент WB/Ozon). Тот же формат, что и Приход.

Воронка продаж: просмотры, добавления в корзину, заказы по товарам. Период задаётся фильтром в шапке. «Применить» перечитывает таблицу из базы; «Обновить базу» в шапке вытягивает данные периода из WB API (Успешное скачивание записывает в базу автоматически).

?Срез воронки из базы за выбранный период. «Расширенный вид» включает все поля отчёта WB: предмет, бренд, рейтинги, остатки, конверсии, WB Клуб, время доставки.

Выкупы: WB не отдаёт эти данные с текущим ключом (нужен доступ «Статистика», метод v1/main). Доступны только Просмотры/Корзина/Заказы/Отмены. При наличии доступа колонки заполнятся после нового скачивания воронки.
